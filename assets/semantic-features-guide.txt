HOW IT WORKS:
─────────────────────────────────────────────────────────────────────────────

  Genre A ────┐
             ├─→ [Fuzzy Matching Engine] ──→ 0.0-1.0 Similarity
  Genre B ────┘

  Three-Step Matching:
    Step 1: Check Explicit Relationships Dictionary
            electronic → synthwave? YES → 0.75

    Step 2: Fall back to String Similarity
            If not found, use SequenceMatcher ratio

    Step 3: Keyword Boost
            If both genres share words, boost score

  Result: Proportional score (0.0-1.0) instead of binary (0 or 1)

SIMILARITY CALCULATION (Euclidean Distance):
─────────────────────────────────────────────────────────────────────────────

Formula: similarity = exp(-k × distance²)

Example 1: calm ↔ chill
  calm:  (0.6, 0.2)
  chill: (0.55, 0.25)

  distance = √[(0.6-0.55)² + (0.2-0.25)²]
           = √[0.0025 + 0.0025]
           = √0.005 = 0.071

  similarity = exp(-1.0 × 0.071²)
             = exp(-0.005) = 0.995
             = 0.95 (rounded)

  Result: ✓ 95% similar (very close!)

Example 2: happy ↔ sad
  happy: (0.9, 0.7)
  sad:   (0.2, 0.3)

  distance = √[(0.9-0.2)² + (0.7-0.3)²]
           = √[0.49 + 0.16]
           = √0.65 = 0.806

  similarity = exp(-1.0 × 0.806²)
             = exp(-0.649) = 0.52
             = 0.43 (rounded)

  Result: ✓ 43% similar (opposite but not zero)

Example 3: calm ↔ energetic
  calm:      (0.6, 0.2)
  energetic: (0.7, 0.95)

  distance = √[(0.6-0.7)² + (0.2-0.95)²]
           = √[0.01 + 0.5625]
           = √0.5725 = 0.756

  similarity = exp(-1.0 × 0.756²)
             = exp(-0.572) = 0.56
             = 0.15 (rounded)

  Result: ✓ 15% similar (quite different!)
